## 购买流程，和三个容易踩的坑

从注册到开机只有五步：注册账号（邮箱加密码即可，无需手机号和实名）→ 选套餐加入购物车 → 填优惠码并点「验证」→ 支付宝、微信或信用卡付款，系统自动开通 → 进控制面板查 IP、密码和 SSH 端口。

真正容易出问题的是三个细节：

**SSH 端口是随机的。** 丽萨主机新机器不使用默认 22 端口，连不上多数情况是端口没查，先到控制面板确认实际端口号，再用 `ssh root@你的IP -p 端口号` 连接。
